\section{Постановка задачи, основные понятия и обозначения}
    Основной задачей работы выступает исследование влияния снижения размерности на качество кластеризации. В качестве базовой модели данных используется смесь центрированных распределений, что обусловлено ключевыми преимуществами: возможность точного контроля параметров генерации данных, а также четкая заданность кластерной структуры с явными центрами. Для объективной оценки качества кластеризации выполняется сравнение результатов алгоритма (принадлежности объектов к кластерам) с эталонными метками генератора данных с использованием метрик \(AMI\), \(ARI\), \(NMI\). В качестве основного алгоритма кластеризации в пространстве меньшей размерности выбран метод \kmeans{}, что обусловлено его оптимальным соответствием природе моделируемых данных.

        Причем присутствуют следующие свойства кластерного разбиения:
        \begin{itemize}
            \item Полнота покрытия: \( \bigcup_{i=1}^{k} C_i = X \) -- каждый объект принадлежит одному из разбиений,
            \item Попарная непересекаемость: \( C_i \cap C_j = \emptyset, \space i \neq j\) -- каждый объект принадлежит только одному кластеру,
            \item Вычисление центроидов: \( \mu_i = \frac{1}{|C_i|} \sum_{x \in C_i} x\) -- центры кластеров вычисляются как среднее значение объектов внутри кластера.
        \end{itemize}

    \subsection{Формулирование задачи кластеризации}
        Формальная запись задачи кластеризации имеет следующий вид: для каждого объекта \(x_i \in X\), необходимо найти отображение \(f\) (\ref{eq:function}), присваивающее каждому объекту в соответствие один из номеров разбиений \(C\).
        \begin{equation}\label{eq:function}
            f: X \to \{1, 2, \dots, k\} \subset \mathbb{Z}^+
        \end{equation}
        В общем виде задача кластеризации на основе центроидов для расстояния Минковского с параметром \(p\) -- есть задача сложной невыпуклой оптимизации функционала качества (\ref{eq:kmeans_problem_p}) \cite{hse:4_course}, которая может быть решена с помощью эвристического алгоритма \kmeans{} для метрики Минковского, где необходимо оптимизировать сумму расстояний между объектами внутри кластеров.
        \begin{equation}\label{eq:kmeans_problem_p}
            W_p(C;\mu) = \sum_{l=1}^k \sum_{x \in C_l} \sum_{j=1}^{d} |x^j - \mu_l^j|^p \to \min
        \end{equation}
        При \(p=2\) получаем стандартную задачу минимизации квадратичного отклонения \ref{eq:kmeans_problem_2}, соответствующую алгоритму \kmeans{}.
        \begin{equation}\label{eq:kmeans_problem_2}
            W(C;\mu) = \sum_{l=1}^k \sum_{x \in C_l} \sum_{j=1}^{d} |x^j - \mu_l^j|^2 \to \min
        \end{equation}

        \subsubsection*{Выбор метода кластеризации}
            В качестве основы для проведения анализа был выбран алгоритм кластеризации \kmeans{}, поскольку \kmeans{} -- легко интерпретируемый подход, основанный на оптимизации суммарного квадратичного отклонения внутри кластеров. Выбор \kmeans{} также обусловлен его основными преимуществами: простотой реализации и  высокой скоростью работы. Его работа состоит из нескольких этапов:
            \begin{enumerate}
                \item \textbf{Инициализация.}
                Фиксируется параметр \(k\) -- число кластеров, которые необходимо найти, после чего центроиды кластеров выбираются случайным образом.
                \item \textbf{Присвоение объектов кластерам.}
                Каждый объект данных присваивается кластеру, чей центроид на основе выбранной метрики расстояния окажется ближе всего.
                \item \textbf{Обновление центроидов.}
                Центроиды пересчитываются на основе объектов из соответствующих кластеров.
                \item Итеративное повторение шагов 1, 2 и 3.
            \end{enumerate}


    \subsection{Критерии оценки результатов кластеризации}
        Для оценки качества алгоритма кластеризации были выбраны три нормализованных показателя \(ARI\), \(AMI\), \(NMI\).

        \paragraph{Индекс совпадений Rand Index (\(RI\))}
            Пусть имеется два варианта разбиения выборки из \(n\) объектов на \(k\) групп: \(C^1\) и \(C^2\). Rand Index (\(RI\)) вычисляется по следующей формуле:
            \begin{equation}
                RI = \frac{\text{число согласованных пар}}{\text{общее число пар}} = \frac{\mathbb{S}+\mathbb{D}}{C_{n}^{2}},
            \end{equation}
            где согласованные пары включают: объекты, находящиеся в одной группе в обоих разбиениях (\(\mathbb{S}\)) и объекты, находящиеся в разных группах в обоих разбиениях (\(\mathbb{D}\)).

        \paragraph{Adjusted Rand Index (\(ARI\))}
            Adjusted Rand Index -- скорректированная версия Rand Index. Принимает значения в промежутке \([0; 1]\), где значение 1 соответствует идентичным кластеризациям, а значение 0 означает, что кластеризации случайны.
            \begin{equation}
                ARI = \frac{RI - \mathbb{E}[RI]}{\max(RI)- \mathbb{E}[RI]},
            \end{equation}
            где \(\mathbb{E}[RI]\) -- оценка математического ожидания \(RI\), а \(\max(RI)\) -- максимальное значение Rand Index, полученное в результате кластеризаций.

        \paragraph{Mutual Information (\(MI\))}
            Mutual Information характеризует количество информации, содержащейся в одном разбиении относительно другого.
            \begin{equation}
                MI(C^1, C^2) = \displaystyle\sum_{i=1}^{|C^1|} \displaystyle\sum_{j=1}^{|C^2|} \frac{|C^1_i \cap C^2_j|}{n} \log\frac{n|C^1_i \cap C^2_j|}{|C^1_i||C^2_j|}
            \end{equation}

        \paragraph{Normalized Mutual Information (\(NMI\))}
            \(NMI\) представляет собой стандартизированную версию взаимной информации, масштабированную до диапазона \([0,1]\), при этом: 1 соответствует полному совпадению кластерных разбиений, а 0 свидетельствует об отсутствии статистической связи между разбиениями:
            \begin{equation}
                NMI(C^1, C^2) = \frac{MI(C^1, C^2)}{\langle H(C^1), H(C^2) \rangle},
            \end{equation}
            причем \(\langle \cdot \rangle\) -- операция вычисления арифметического среднего, а энтропия \(H\) вычисляется как:
            \begin{equation}
                H(C) = -\sum_{i=1}^{|C|} \frac{|C_i|}{n} \log\left(\frac{|C_i|}{n}\right).
            \end{equation}

        \paragraph{Adjusted Mutual Information (\(AMI\))}
            Метрика \(AMI\) представляет собой модифицированный вариант \(MI\), где производится нормировка на её максимально возможное значение:
            \begin{equation}
                AMI(C^1, C^2) = \frac{MI(C^1, C^2) - \mathbb{E}[MI(C^1, C^2)]}{ \langle H(C^1), H(C^2) \rangle - \mathbb{E}[MI(C^1, C^2)]}.
            \end{equation}
